# DogExpress Games

Premium ve doğal tasarımlı, çevrimdışı Android deneme sürümü. Üç örnek oyun, kategori filtresi, adım adım oyun akışı ve cihazda saklanan ilerleme içerir. Android 8.0 veya üzeri gerekir.

## GitHub Actions ile test APK’sı

1. **Actions → Android APK** bölümünde başarılı bir çalıştırmayı aç.
2. **Artifacts** altındaki **dogexpress-games-test** paketini indir.
3. ZIP içindeki `app-debug.apk` dosyasını Android cihazında dene.

Derleme GitHub’da çalışır. Deneme imzası derlemeler arasında değişebilir ve önceki kurulum üzerine yüklemeyi engelleyebilir. Uygulamayı kaldırmak yerel ilerlemeyi siler.
